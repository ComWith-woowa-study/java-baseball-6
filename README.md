## 기능 요구 사항

### 입력
-[ ] 서로 다른 3자리의 수를 입력 가능하다.
  -[ ] 각 자리는 1~9 사이 정수여야 한다. 
  -[ ] 중복은 불가능하다. 
-[ ] 게임이 끝난 경우 재시작은 1, 종료는 2로만 가능하다.

### 출력
-[ ] 스트라이크, 볼, 낫싱을 규칙에 맞게 출력한다.

### 기능
-[ ] 컴퓨터는 1에서 9까지 서로 다른 임의의 수 3개를 선택한다.
-[ ] 같은 수가 같은 자리에 있으면 스트라이크
  -[ ] 스트라이크가 몇개인지 계산한다.
-[ ] 같은 수가 다른 자리에 있으면 볼
  -[ ] 볼이 몇개인지 계산한다.
-[ ] 같은 수가 전혀 없으면 낫싱
-[ ] 3스트라이크가 나올 때까지 반복
-[ ] 3스트라이크시 게임 종료
